Connect Gmail

This app talks to Gmail directly from your browser via Google's own sign-in — there's no server in between. You'll need a free OAuth Client ID from Google Cloud Console (one-time setup):

  1. Create a project at console.cloud.google.com, then enable the Gmail API.
  2. Set up the OAuth consent screen — choose External and add your own Google account as a test user.
  3. Create an OAuth Client ID of type Web application.
  4. Add the exact URL this page is running on as an Authorized JavaScript origin (must be served over http/https — opening the file directly won't work).
  5. Paste the Client ID below.

Requests the gmail.modify scope (Gmail has no narrower scope for applying labels) — but this app only ever reads mail and applies labels. It never archives, trashes, or marks anything read.
